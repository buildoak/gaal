# Gaal Remotion Promo

Terminal-style Remotion workspace for a light Gaal promo video.

## Commands

```bash
npm run dev
npm run lint
npm run build
npx remotion render GaalTerminalPromo out/gaal-terminal-promo.mp4
```

## Direction

- Motion style: crisp terminal/UI panels, no cinematic footage.
- First message: agents do real work, but their evidence gets buried in traces.
- Core demo: `gaal index`, `gaal who wrote`, `gaal search`, and `gaal recall`.
- Closing line: local memory for AI coding-agent work. Not a cloud. Not a daemon. Just evidence.

Rendering uses Remotion's browser-based renderer. On the Mac Mini, get explicit approval before running local render/browser operations.
